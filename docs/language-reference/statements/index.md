# Statements

Statements are the executable instructions of a RAD Basic program. This section covers control flow, I/O operations, procedure declarations, and more.

---

## In this section

| Statement | Description |
|---|---|
| [Call](call.md) | Transfers control to a Sub or Function procedure |
| [Do...Loop](do-loop.md) | Repeats a block of statements while or until a condition is true |
| [For...Next](for-next.md) | Repeats a block of statements a specified number of times |
| [If...Then...Else](if-then-else.md) | Conditionally executes a block of statements |
| [Line Input](line-input.md) | Reads a line from an open file into a variable |
| [Open](open.md) | Opens a file for input, output, or appending |
| [Print](print.md) | Writes output to the screen or to an open file |
| [Select Case](select-case.md) | Executes one of several blocks of statements based on a value |
| [Sub](sub.md) | Declares a Sub procedure |
| [While...Wend](while-wend.md) | Repeats a block of statements while a condition is true |
