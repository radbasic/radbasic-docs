# String Functions

Functions for creating, searching, and manipulating strings in RAD Basic.

---

## In this section

| Function | Description |
|---|---|
| [Asc](asc.md) | Returns the ASCII code of the first character of a string |
| [Chr](chr.md) | Returns the character corresponding to an ASCII code |
| [InStr](instr.md) | Returns the position of a substring within a string |
| [LCase](lcase.md) | Converts a string to lowercase |
| [Left](left.md) | Returns a specified number of characters from the left of a string |
| [Len](len.md) | Returns the number of characters in a string |
| [Mid](mid.md) | Returns a substring from within a string |
| [Replace](replace.md) | Replaces occurrences of a substring within a string |
| [Right](right.md) | Returns a specified number of characters from the right of a string |
| [UCase](ucase.md) | Converts a string to uppercase |
